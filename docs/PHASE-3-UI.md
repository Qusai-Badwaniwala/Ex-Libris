# Phase 3 UI implementation brief

## Direction contract

THESIS: Operate. Find an owned work locally or deliberately acquire a new one;
these are separate tasks, not competing search bars.

OWN-WORLD: Inherit the immutable Claude Design prototype, final tokens, three
self-hosted typefaces, hairlines and sheet vocabulary. No redesign.

STORY: Search the library, open the catalogue from its existing door, inspect
format and source, confirm editable metadata and status, save on-device.

FIRST VIEWPORT: Preserve the prototype's search header and grouped rows, its
92%-height catalogue sheet, and illustrated index download screen with real
byte progress and a usable exit.

FORM: Existing precisely specified surfaces; no concept seed or generated comp.
Use `design/Ex Libris.dc.html` as the visual reference, plus E-052/E-054 approvals.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

The immutable design package is this workspace's existing design documentation;
do not generate a competing design contract or edit that package. No new raster
assets are required. Physical-phone latency remains a separate acceptance gate.
