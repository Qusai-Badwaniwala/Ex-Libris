# Project rules — Ex Libris

**File size is never a constraint.** Do not drop, downsample, simplify or substitute an asset because of its file weight. A 1 GB asset is acceptable. Never raise file size as an objection or a caveat.

**Illustration.** Brief §3.5's "one hand, one line weight, one ink" is held loosely — the user supplies flat-colour Storyset figures rather than monoline drawings. What still binds: illustration appears only where content does not, never behind text, never in the chrome. Consistency comes from the shared `--il-*` recolour ramp, not from a single drawing hand.

**Reference documents** live at `docs/brief.md` and `docs/schema.md` (extracted from the .docx uploads — read these, not the .docx).

**Handoff files** (`HANDOFF.md`, `DECISIONS.md`, `OPEN-QUESTIONS.md`, `MOTION.md`, `COMPONENTS.md`, `ILLUSTRATION-NOTES.md`) are updated at the end of every working session and after every significant decision.
