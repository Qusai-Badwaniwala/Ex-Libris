Ex Libris · illustration plan · all thirteen

Where each one goes

All thirteen are used, each in one place and only in places that would otherwise be empty. Every fill has been remapped onto a ten-step ramp, so drawings by five different illustrators read as one set. Shown here at roughly the size each appears in the app.

Placements

Bookplate
magic tree · cuate

First run, and the About screen forever after. The most elaborate placement in the app, sitting under the engraved frame and the owner's name. A tree of books is close enough to a bookplate device to carry the screen.

Empty library
dragon · rafiki

The second screen anyone ever sees, and the one that has to be an invitation rather than an apology. The dragon is the largest illustration in the app and the only one allowed to fill a screen.

Corpus download
library · pana · 750×500

The only wide file in the set, which is exactly what a first-run progress screen wants. Sits above honest progress and a skip control, and the app stays usable while it runs.

Finish moment
cherry tree · pana

Behind the green tick, at 30% scale and low opacity — the one place illustration sits behind content rather than instead of it, and the only exception I am asking for. Never congratulates. It is a mark, not a celebration.

Stats, opening plate
knowledge · rafiki

Stats is a page in a book, not a dashboard, so it opens with a plate the way a chapter does. Above the year heading, never between the figures.

Year divider, Stats
cherry tree · amico

Between years in the finished-by-year run. Same tree as the finish moment in a different season, which is the quiet joke: one tree per book finished, one per year survived.

Empty wishlist
cherry blossom · cuate

A wishlist is a list of things not yet arrived, which is what a tree in blossom is. Sits above Surprise me, which is disabled until there is something to surprise you with.

Empty notes
research paper · amico

The Notes feed with nothing in it. Notes here are for working things out, not for highlights, and the drawing says that without a word of copy having to.

Note editor, blank
studying · bro

Behind the empty body field, at low opacity, and it clears the moment the first character is typed. The only illustration that ever animates out.

Empty shelf
library · rafiki

A format screen with nothing on it — the manhwa shelf before the first manhwa. Distinct from the empty library, because the library is not empty; this shelf is.

No search results
bibliophile · rafiki

Small, 120px, under the search field. The copy below it offers to add the work by hand, because for web novels a miss is not a mistake — it is just the corpus running out.

Empty trash
bibliophile · bro

The quietest placement, at 120px. Trash is a utility screen and an empty one is good news, so it gets the smallest drawing in the set and one line of copy.

Backup, no history
bibliophile · pana

Before the first automatic backup has run. Also the restore screen's resting state, above the three import paths.

Two things this changes

The brief said illustration never sits behind text. The finish moment and the blank note editor both break that, deliberately, at low opacity — those two screens are almost entirely empty and the alternative is a drawing floating beside nothing. Everywhere else the rule holds exactly.

The brief also asked for a recurring figure appearing five to eight times. These are thirteen one-offs instead, with continuity carried by the colour ramp rather than by a character. That is a weaker thread, and it is the trade for using drawings you chose over drawings I would have had to make.
